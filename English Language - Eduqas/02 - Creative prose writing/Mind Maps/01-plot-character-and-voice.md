# Plot, character and voice

## A choice matters

- **Café worker:** catch the bus or return the glasses. Both wishes make the choice meaningful.

- The encounter exposes a mistaken judgement, creating a change without a dramatic new subplot.

Shows an event changing the character, rather than merely adding more incidents.

## Open a useful question

- **Significant object:** abandoned glasses suggest someone missing and something needing attention.

- Give enough information to follow the event. Confusion is not the same as suspense.

## Develop the viewpoint

- **First person:** report what I notice, remember and infer. Other minds are not automatically known.

- A brief memory can explain the present concern; return clearly to the main event.

## Show and summarise

- **Close detail:** a repeated pocket search shows anxiety.

- **Summary:** an afternoon’s work can pass in a sentence, leaving space for the decisive encounter.

## Let dialogue act

- **Purpose:** reveal a relationship, pressure a choice or move the event.

- Use small actions beside speech. Avoid long exchanges that explain what both speakers already know.

## Make the ending earned

- **Motif:** an object returns with changed meaning. A photograph can preserve the marks without stopping the move.

- Resolve the main episode before adding another plot. Avoid an unprepared twist that cancels the story.
