# Instrumental analysis and reliable conclusions

## Advantages

Rapid results.

Sensitive to small quantities.

Accurate when appropriately calibrated.

Can measure concentrations and resolve mixtures.

## Flame emission

Sample enters flame.

Emitted light passes through spectroscope.

Read line spectrum.

Compare with reference spectra.

## Identify ions

Match line positions/patterns.

Mixtures can contain several line sets.

Overall colour alone can mask components.

Use reference evidence rather than guesses.

## Concentration

Compare suitable signal with calibration.

Read supplied axes and units.

No universal signal-to-concentration conversion.

Measurement resolution and calibration matter.

## Chemical versus instrumental

Simple tests cheap and accessible.

Instruments can detect smaller samples quickly.

Equipment/calibration require resources.

Select method for the stated task.

## Justified conclusions

Name test, observation and inferred ion.

Use an extra test for ambiguous white precipitate.

One chromatography spot need not prove purity.

Repeat uncertain results with clean samples.
