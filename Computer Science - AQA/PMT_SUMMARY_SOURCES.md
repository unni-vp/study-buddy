# PMT Computer Science source and coverage record

Internal reference for authoring and maintenance. Student reading pages keep source and tracking sections hidden.

The AQA GCSE Summary Notes links were downloaded from [PMT’s AQA revision directory](https://www.physicsandmathstutor.com/computer-science-revision/gcse-aqa/) on 20 October 2026. The PDFs label themselves Advanced Notes internally. All eight originals retain their printed attribution and CC BY-NC-ND 4.0 licence, without modification.

The PDFs supply a coverage checklist. The revised AQA 8525 specification for first exams in 2027 determines assessed scope. The site explanations, examples and new diagrams are independently written. Each topic’s `pmt-summary-review.json` maps every substantive PDF page to note headings and records corrections or scope exclusions. Page 1 of each PDF is its cover and licence.

## Review decisions

- Source claims are checked rather than copied uncritically. Examples include Unicode storage width, random values repeating, boundary tests, clock cycles versus instructions, pharming, and required linking conditions in two-table SQL queries.
- The 2027 specification does not require the source’s optical-disc mechanisms, bus/star topology treatment, additional named protocols or detailed lists of statutory offences. Those are not silently presented as new mandatory material. Supporting explanations such as lossy/lossless compression remain.
- Recent comparison tables, the original BANANA Huffman example and existing useful diagrams are retained.
- Longer menus remain flat. Each card opens a reading page directly, with Previous/Next navigation and a complete print-all view.
- Each topic was built, checked at desktop and mobile widths and pushed separately. Code examples were compiled; the Programming examples were also executed with controlled inputs, and all 16 SQL examples were executed against fresh copies of the displayed tables.
