Network security

Why network security matters

Network security protects systems and data from unauthorised access, alteration, damage and disruption. A strong design uses several controls because each deals with different risks.

Possible consequences of weak security include data theft, changed files, unavailable services, financial loss and damage to reputation.

Authentication and encryption

FeatureAuthenticationEncryption
PurposeChecks identity before access is granted.Makes data unreadable without the appropriate key.
ExampleCheck a username/password or another identity factor.Transform plaintext into ciphertext before transmission.
LimitationChecking identity does not itself hide intercepted traffic.An authorised recipient still needs the required key; encryption does not decide account permissions.

Authentication controls who enters. Encryption protects data if traffic is intercepted. They work together but solve different problems.

Firewalls and MAC address filtering

FeatureFirewallMAC address filtering
What is checked?Incoming and outgoing network traffic.The physical address associated with a device’s network adapter.
DecisionAllows or blocks traffic using defined security rules.Allows or blocks devices using their MAC addresses.
LimitationIncorrect rules may block legitimate traffic or allow threats.Addresses can be copied or spoofed, so this should not be the only defence.

Use layered security: authentication, encryption, firewall rules and device controls support one another.
