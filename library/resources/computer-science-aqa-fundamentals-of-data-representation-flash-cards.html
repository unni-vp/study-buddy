QuestionExplain and compare

Explain the difference between sampling rate and sample resolution.

Select the card or press Space to reveal the answer.

Answer
  • Sampling rate is the number of amplitude measurements each second, measured in Hz. Sample resolution is the bits used per measurement and determines the available amplitude values. They can be changed independently.

QuestionMulti-step application

Explain how increasing bitmap dimensions and colour depth affects the image and file size.

Select the card or press Space to reveal the answer.

Answer
  • More pixels can show finer spatial detail.
  • More pixels increase width × height, so more pixel codes are stored.
  • Greater colour depth allows more possible colours for each pixel.
  • Both changes increase the number of bits and therefore the file size.
QuestionMulti-step application

Explain how an analogue sound wave is represented digitally.

Select the card or press Space to reveal the answer.

Answer
  • The wave's amplitude is measured at regular time intervals.
  • Each measurement is a sample.
  • The sample is rounded to one of the available levels.
  • Each level is stored as a binary value using the chosen sample resolution.
QuestionMulti-step application

Explain how Huffman coding compresses data.

Select the card or press Space to reveal the answer.

Answer
  • Count how frequently each symbol occurs.
  • Build a tree by repeatedly combining the two least frequent nodes.
  • Assign 0 and 1 to branches and read each root-to-leaf path as a code.
  • Frequent symbols receive shorter codes, reducing the total number of bits.
QuestionMulti-step application

A text contains 40 characters. Calculate its uncompressed 7-bit ASCII size and explain how to find the number of bits saved by a 190-bit Huffman encoding.

Select the card or press Space to reveal the answer.

Answer
  • ASCII size = 40 × 7 = 280 bits.
  • Huffman size is 190 bits.
  • Bits saved = 280 − 190.
  • The encoding saves 90 bits.

Why are Huffman codes prefix-free?

Answer
