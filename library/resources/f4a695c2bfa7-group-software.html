System software

System and application software

SoftwareMain purposeExamples
System softwareManages computer resources and provides a platform for applications.Operating system, device drivers and utility programs.
Application softwarePerforms tasks for the end user.Word processor or image editor.

An operating system manages:

  • processors and scheduling
  • memory allocation
  • input/output devices and drivers
  • applications and files
  • users, permissions and security

Utility software maintains, protects or configures a system. Examples include backup tools, anti-malware software, compression tools and disk-management utilities.

What the operating system actually does

ResponsibilityExplanation
Processor managementIt allocates processor time to running tasks, allowing several applications to make progress.
Memory managementIt allocates memory to programs and tracks which areas are in use, helping keep their working data separate.
Input/output managementIt coordinates communication with devices, using drivers to handle device-specific instructions.
Application managementIt provides services that let applications start, run and use hardware without controlling every component themselves.
Security managementIt manages accounts and permissions so users and programs can access only authorised resources.

Think of the operating system as a school office coordinating shared rooms and equipment. Applications can request resources instead of each having to organise the entire school.

A utility has a more focused maintenance job. A backup utility copies data so it can be recovered after a failure; anti-malware software detects and deals with malicious files; compression software reduces storage or transfer requirements. These are system-support tasks rather than the end-user task of writing an essay.
