QuestionConjugate surd

QuestionHcf application

A florist has 96 roses and 144 tulips. She makes the greatest possible number of identical bunches, using every flower. How many bunches are made, and what does each contain?

Select the card or press Space to reveal the answer.

Answer
  • The number of bunches must divide both totals. HCF(96,144) = 48.
  • Each bunch contains 96 ÷ 48 = 2 roses.
  • Each also contains 144 ÷ 48 = 3 tulips. There are 48 bunches.
QuestionRoot bounds

Without using a calculator, show that √50 lies between 7 and 8. Then decide whether it is nearer 7 or 8.

Select the card or press Space to reveal the answer.

Answer
