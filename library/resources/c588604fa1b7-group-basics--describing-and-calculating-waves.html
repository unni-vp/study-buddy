Waves and measurements

Describing and calculating waves

QuantityMeaningUnit
AmplitudeMaximum displacement from the resting positionmetre, m
Wavelength λDistance between equivalent points on adjacent waves, such as crest to crest or compression to compressionmetre, m
Frequency fNumber of complete waves passing a point each secondhertz, Hz
Period TTime for one complete vibrationsecond, s
Wave speed vSpeed at which the disturbance or energy travelsmetre per second, m/s

Wave speed: v = fλ

Period: T = 1/f

Rearrange before substituting if it helps:

  • To find wavelength: λ = v/f.
  • To find frequency: f = v/λ.

Example: water ripples have f = 8.0 Hz and λ = 2.5 cm.

  1. Convert wavelength: 2.5 cm = 0.025 m.
  2. v = 8.0 × 0.025 = 0.20 m/s.
  3. T = 1/8.0 = 0.125 s.

A graph against distance gives wavelength. A graph against time gives period. Amplitude is not crest-to-trough height: that height is twice the amplitude.

When a wave enters a new medium, its frequency stays the same because the source still produces the same number of vibrations each second. A change in speed therefore changes wavelength.

Example: sound at 500 Hz

Using the supplied speeds:

  • In air: λ = 340 ÷ 500 = 0.68 m.
  • In water: λ = 1,500 ÷ 500 = 3.0 m.

Which quantity is being changed?

SituationWhat stays fixedWhat changes
Increase source frequency in the same medium under unchanged conditions.Wave speed stays approximately the same.Wavelength decreases because λ = v/f.
A wave crosses into a medium where it travels more slowly.Frequency stays the same.Wavelength decreases.
Increase sound amplitude without changing frequency.Pitch stays the same.The sound is generally louder.

For example, if sound speed is 340 m/s, raising frequency from 170 Hz to 340 Hz changes wavelength from 2.0 m to 1.0 m. It does not double the speed.

On an oscilloscope, if four complete cycles occupy 8.0 ms, one period is 2.0 ms = 0.0020 s. Frequency is 1 ÷ 0.0020 = 500 Hz. Count the intervals between matching points, not simply the number of peaks.
