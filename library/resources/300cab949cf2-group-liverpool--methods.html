Liverpool fieldwork

Liverpool data-collection methods

DataHow it was collectedWhat it helped show
Environmental qualityLitter, graffiti, noise, traffic, building condition and attractiveness were scored; scores were totalledDifferences in the quality of each sampled site
Pedestrian flowPeople passing a fixed point were counted for a set timeHow busy each site was
Land useField sketches and land-use maps recorded shops, services and other buildingsThe function and character of each area

The sample was systematic because data was collected at regular points along a route. Using several sites allowed busier central areas to be compared with quieter streets.
