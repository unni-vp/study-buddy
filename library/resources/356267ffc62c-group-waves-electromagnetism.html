Waves & electromagnetism equations

Equations: waves and electromagnetism

RelationshipUse or condition
T = 1/fT is period.
v = fλFrequency stays unchanged at a medium boundary.
Magnification = image height/object heightUse matching height units. Magnification has no unit.
F = BIlConductor perpendicular to the field. Use length inside the field.
Vₚ/Vₛ = nₚ/nₛKeep matching subscripts together.
VₚIₚ = VₛIₛEqual input and output power for an ideal transformer.

For an echo, use the wave relationship plus the journey: one-way distance = vt/2. The time includes the return trip.

For a real transformer with given efficiency, use input power = output power/efficiency before finding current.
