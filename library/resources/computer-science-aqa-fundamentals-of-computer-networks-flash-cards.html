QuestionApply and calculate

Answer

  • It allows or blocks traffic according to those rules.
QuestionApply and calculate

Explain how MAC address filtering controls network access and give one limitation.

Select the card or press Space to reveal the answer.

Answer
  • Filtering compares an adapter’s MAC address with allow or block rules. It controls devices rather than identifying their current users. An address can be copied or spoofed, so use it with authentication and encryption.
QuestionApply and calculate

State the job of the application, transport and internet layers.

Select the card or press Space to reveal the answer.

Answer
  • Application: provides services used by network applications.
  • Transport: sets up end-to-end communication and manages packet delivery.
  • Internet: addresses and routes packets across networks.
QuestionApply and calculate

Select the card or press Space to reveal the answer.

Answer
  • Protocols provide agreed communication rules so different devices can interpret exchanged data. The rules can cover formatting, addressing, transmission and responses to errors; each protocol handles its particular part of the job.

QuestionMulti-step application

Compare wired and wireless connections for classroom computers.

Select the card or press Space to reveal the answer.

Answer
  • Wired links are normally stable, low latency and less affected by radio interference.
  • They restrict device location and require cable installation.
  • Wireless links support mobile devices and are easier to extend.
  • Wireless performance can fall because of distance, obstacles, interference and congestion, and strong security is required.
QuestionMulti-step application

Describe how the four TCP/IP layers take part when a browser requests a web page.

Select the card or press Space to reveal the answer.

Answer
  • The application layer creates an HTTP or HTTPS request.
  • TCP at the transport layer manages the end-to-end communication.
  • IP at the internet layer adds addressing and routes packets.
  • The link layer transmits data using the local NIC and network hardware.
QuestionMulti-step application

Explain how several network-security methods work together.

Select the card or press Space to reveal the answer.

Answer
  • Authentication limits access to recognised users.
  • Encryption protects data if traffic is intercepted.
  • A firewall blocks traffic that breaks defined rules.
  • MAC filtering can restrict devices, so the combined controls cover identity, data, connections and hardware access.

QuestionFocused recall

Answer

QuestionFocused recall

Distinguish bandwidth from latency.

Select the card or press Space to reveal the answer.

Answer
  • Bandwidth is the amount of data a connection can carry per second. Latency is communication delay. A high-bandwidth connection can still have noticeable delay.

QuestionFocused recall

What is the job of the link layer, and which components belong there?

Select the card or press Space to reveal the answer.

Answer
  • It handles the local connection and network hardware. The network interface card and operating-system device drivers operate here.
QuestionFocused recall
