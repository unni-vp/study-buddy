QuestionExplain and compare

Explain the difference between a WHILE loop and a REPEAT ... UNTIL loop.

Select the card or press Space to reveal the answer.

Answer
  • WHILE tests its condition before the body, so the body may run zero times.
  • REPEAT ... UNTIL tests after the body, so the body runs at least once.

QuestionMulti-step application

Write pseudocode that repeatedly inputs a mark until it is from 0 to 100 inclusive.

Select the card or press Space to reveal the answer.

WHILE mark < 0 OR mark > 100
    OUTPUT "Enter 0 to 100"
    mark ← USERINPUT
ENDWHILE
