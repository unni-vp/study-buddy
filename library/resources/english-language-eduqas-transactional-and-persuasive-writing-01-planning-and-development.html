Planning & development

Decode the request

  • Identify form, audience, purpose and context. Use a supplied title.
  • Write: “I want this reader to ... because ...”. Do not change the task to fit a memorised answer.

Select a clear position

  • For an argument, decide your main claim. For advice, decide the useful action; for review, your judgement.
  • Consider the reader’s needs and worries. An editor can publish views, but cannot personally change a school rule.

Different points

  • For clubs: learning a skill, meeting people, fitting attendance around commitments.
  • Three versions of “clubs are fun” are repetition. Each paragraph should add something new.

Develop one point

  • Point → detail → explanation → reader. Use this as a thinking route, not a fixed formula.
  • Example: small coding task → visible success → unfamiliar skills feel learnable. Explain the connection.

Order paragraph jobs

  • Persuade: concern → benefits → obstacle and response → action.
  • Advise: preparation → first action → likely difficulty → next step. Discuss: weigh views → reasoned judgement.

Plan quickly

  • Use brief paragraph notes and one useful example for each key point. No compulsory paragraph count.
  • Check that the ending follows from the plan. Keep time to draft and edit both tasks.
