Input, strings and random values

Working with strings

A string is a sequence of characters. Positions identify individual characters, while a substring contains a selected sequence of characters.

Use text = "BIOLOGY" in these examples:

OperationPythonResult and explanation
Find the lengthlen(text)The result is 7, because every character counts.
Access a positiontext[2]The result is "O", because indexing starts at 0.
Find a positiontext.find("LOG")The result is 3, the start index of that sequence. It returns −1 if absent.
Extract a substringtext[1:4]The result is "IOL". Indices 1, 2 and 3 are included; index 4 is excluded.
Concatenate strings"Bio" + "logy"The result is "Biology". A space is added only if one is supplied.

"7" + "2" gives "72", while int("7") + int("2") gives 9. Converting a string to a number changes the operation from joining text to arithmetic.

ConversionPython exampleResult
String to integerint("42")The integer 42.
String to realfloat("3.5")The real value 3.5.
Integer to stringstr(42)The string "42".
Real to stringstr(3.5)The string "3.5".
Character to codeord("A")The character code 65.
Code to characterchr(65)The character "A".

A conversion requires suitable input. The string "four" cannot be converted using int. Character codes represent characters, so the code of the digit "7" is not the number 7.
