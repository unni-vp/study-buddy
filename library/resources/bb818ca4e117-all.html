Fundamentals of computer networks

Networks, benefits and risks

A computer network is two or more computers or devices connected so they can communicate and share resources.

Think of a network as a transport system: devices are destinations, links are roads and protocols are agreed traffic rules.

AspectBenefitPossible disadvantage
Shared resourcesUsers can share files, printers and an internet connection.Setup, equipment and maintenance cost money.
CommunicationUsers can collaborate and access shared services from different devices.Congestion can reduce performance.
Central managementAccounts, updates and backups can be managed centrally.Users may depend on network equipment and services remaining available.
Connected devicesInformation is easier to exchange.Malware or faults can spread; security and privacy need protection.

PAN, LAN and WAN

TypeScale and ownershipExample
PANVery short range around one person; Bluetooth is required herePhone connected to wireless earbuds
LANSmall geographical area, often owned and managed by one person or organisationSchool or home network
WANWide geographical area, often using third-party infrastructure and distributed ownershipThe Internet

Classify a network using geographical scale, how devices connect and who owns or manages the infrastructure.

Wired and wireless networks

FeatureWired networkWireless network
ConnectionA cable connects each device.Radio signals connect devices without a cable to each one.
MobilityMovement is restricted by cables.Users can move around within coverage.
InstallationCabling can cost money and disrupt a building.Convenient where cables are difficult; mobile devices are easier to add.
PerformanceUsually stable, with low latency and less radio interference.Distance, obstacles, interference and congestion can reduce signal quality.
SecurityPhysical access makes interception harder, but a cable does not guarantee security.Signals may extend beyond a building, so authentication and encryption are important.
Suitable useFixed devices needing a stable connection.Phones and tablets needing mobility.

Copper and fibre-optic cable

FeatureCopper cableFibre-optic cable
SignalCarries electrical signals.Carries light.
Suitable useCommon, relatively inexpensive shorter links.High-bandwidth links over long distances.
Trade-offCan be affected by electromagnetic interference.Resists electromagnetic interference, but installation can cost more.

Choose a connection for the stated situation. Do not assume one option is always faster or more secure in every installation.

Protocols

A network protocol is an agreed set of rules for communication. Both ends must agree how data is formatted, addressed, sent and received.

ProtocolFull namePurpose
TCPTransmission Control ProtocolSets up reliable communication, divides data into packets and supports checking/reassembly
IPInternet ProtocolAddresses and routes packets between networks
HTTPHypertext Transfer ProtocolTransfers web pages and related web data
HTTPSHypertext Transfer Protocol SecureEncrypted, authenticated version of HTTP for more secure web communication
SMTPSimple Mail Transfer ProtocolSends email from a client to a server and between mail servers
IMAPInternet Message Access ProtocolAccesses and manages email kept on a mail server, synchronising folders and status

TCP and IP

FeatureTCPIP
Main jobManages reliable end-to-end communication, including ordering data and detecting missing data.Addresses and routes packets between networks.
TCP/IP layerTransport.Internet.
How they work togetherHelps the destination reconstruct the correct data stream.Gets addressed packets towards the destination.

HTTP and HTTPS

FeatureHTTPHTTPS
UseTransfers web pages and related web data.Performs web communication using an encrypted connection.
Data in transitDoes not itself encrypt the connection.Protects transmitted data against being read by an interceptor.
AuthenticationDoes not itself authenticate the server through a certificate.Uses certificates to help authenticate the server connection.

Do not write that HTTPS makes a website completely safe. It protects data in transit and helps authenticate the connection; the site or user's device could still be harmful or compromised.

SMTP and IMAP

FeatureSMTPIMAP
Main jobSends email.Accesses and manages email stored on a server.
CommunicationClient to outgoing mail server, and between mail servers.An email client communicates with the server holding the mailbox.
Example actionSend a new message to somebody else.Read a message or synchronise folders and read/unread status across devices.
What to distinguishSending a message does not replace mailbox access.Reading or organising a mailbox is different from sending a message.

Why network security matters

Network security protects systems and data from unauthorised access, alteration, damage and disruption. A strong design uses several controls because each deals with different risks.

Possible consequences of weak security include data theft, changed files, unavailable services, financial loss and damage to reputation.

Authentication and encryption

FeatureAuthenticationEncryption
PurposeChecks identity before access is granted.Makes data unreadable without the appropriate key.
ExampleCheck a username/password or another identity factor.Transform plaintext into ciphertext before transmission.
LimitationChecking identity does not itself hide intercepted traffic.An authorised recipient still needs the required key; encryption does not decide account permissions.

Authentication controls who enters. Encryption protects data if traffic is intercepted. They work together but solve different problems.

Firewalls and MAC address filtering

FeatureFirewallMAC address filtering
What is checked?Incoming and outgoing network traffic.The physical address associated with a device’s network adapter.
DecisionAllows or blocks traffic using defined security rules.Allows or blocks devices using their MAC addresses.
LimitationIncorrect rules may block legitimate traffic or allow threats.Addresses can be copied or spoofed, so this should not be the only defence.

Use layered security: authentication, encryption, firewall rules and device controls support one another.

The four-layer TCP/IP model

Layering divides networking into manageable jobs. Each layer provides services to the layer above and uses the layer below.

LayerMain jobNamed protocols/components
ApplicationNetwork applications and user-facing servicesHTTP, HTTPS, SMTP, IMAP; browsers and email programs
TransportSets up end-to-end communication and agrees details such as packet sizeTCP
InternetAddresses, packages and routes packets across networksIP
LinkWorks with local network hardware and transmissionNIC and operating-system device drivers

When data is sent, each layer adds information needed for its job. At the destination, layers process and remove the relevant information. This separation makes protocols easier to develop and replace without redesigning the whole system.

Following a web request

  1. At the application layer, the browser creates an HTTP or HTTPS request.
  2. TCP at the transport layer manages the connection and packet delivery.
  3. IP at the internet layer adds addressing and routes packets.
  4. The link layer sends data using the local network hardware.
  5. The destination processes the layers in reverse to deliver the request to the web service.

Packets may take different routes. TCP helps the receiving host detect missing data and put received data into the correct order.

Comparison checklist

  • Link each advantage or disadvantage to the stated user and task.
  • For PAN/LAN/WAN, mention scale and management, not speed alone.
  • Distinguish sending email with SMTP from accessing server-held email with IMAP.
  • Distinguish identity checking from protecting intercepted data.
  • Name the TCP/IP layer and then state its job.
