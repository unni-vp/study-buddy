QuestionExplain and compare

Explain a relational database.

Select the card or press Space to reveal the answer.

Answer
  • It stores data in related tables.
  • Tables can be linked by matching a foreign key to a primary key.
QuestionExplain and compare

Explain why a person's name is usually a poor primary key.

Select the card or press Space to reveal the answer.

Answer
  • Different people can have the same name.
  • A primary key must identify each record uniquely, so a unique ID is more suitable.
QuestionExplain and compare

Answer
  • Primary key: LoanID.
  • Foreign key: PupilID, linking to the pupil identified in Pupils.
QuestionExplain and compare

Explain why the same PupilID may appear in several Loan records.

Select the card or press Space to reveal the answer.

Answer
  • One pupil may borrow several books.
  • Each loan has a unique LoanID but uses the same foreign key to identify that pupil.
QuestionExplain and compare

Explain the difference between data redundancy and data inconsistency.

Select the card or press Space to reveal the answer.

Answer
  • Redundancy is unnecessary duplication of data.
  • Inconsistency occurs when copies disagree, for example two different addresses for the same pupil.

QuestionApply and calculate

Explain how linking a pupil table to a loan table can reduce inconsistency.

Select the card or press Space to reveal the answer.

Answer
  • Store the pupil's name once in the pupil table.
  • Each loan stores the PupilID foreign key, rather than another copy of the name.
  • A name change is made in one record, avoiding conflicting copies in different loan records.

QuestionApply and calculate

Loans has fields LoanID, PupilID, BookTitle and DaysLoaned. Write SQL to return BookTitle for loans lasting at least 14 days but no more than 21 days.

Answer

FROM Loans

QuestionApply and calculate

Explain why this condition cannot match any record: YearGroup = 10 AND YearGroup = 11.

Select the card or press Space to reveal the answer.

Answer
  • One record has one value for YearGroup.
  • AND requires both conditions to be true, but that value cannot be both 10 and 11.
  • Use OR to match either year group.

QuestionMulti-step application

An administrator runs this query by mistake. Explain its effect and show a corrected version that affects only pupil 101.

UPDATE Pupils
SET YearGroup = 11;

Select the card or press Space to reveal the answer.

Answer

QuestionMulti-step application

Loans has fields LoanID, PupilID, BookTitle and DaysLoaned. Write SQL to show BookTitle and DaysLoaned for loans longer than 7 days, longest first.

QuestionMulti-step application

A pupil table has records (101, Shreya), (102, Amir), (103, Mia). A loan table has matching PupilID values 101, 101 and 102. Describe the rows produced by matching Pupils.PupilID to Loans.PupilID, and explain why the match matters.

Select the card or press Space to reveal the answer.

Answer
  • Shreya appears in two matching rows, one for each loan.
  • Amir appears in one matching row.
  • Mia has no matching loan, so does not appear in this matching result.
  • Matching the keys links each loan to the correct pupil; without a linking condition, unrelated pupil and loan rows could be combined.
